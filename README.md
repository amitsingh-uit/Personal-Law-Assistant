Personal Law Assistant ⚖️
A web-based platform designed to simplify legal awareness by helping users understand basic legal queries through an interactive interface.

🚀 Project Overview
The Personal Law Assistant aims to bridge the gap between complex legal jargon and common citizens. It provides a user-friendly platform where individuals can submit questions regarding basic law and receive relevant information powered by API integration.

🛠️ Tech Stack Used
Frontend: HTML5, CSS3 
Scripting: JavaScript (for interactivity and API calls)
Integration: REST APIs (to fetch legal data and responses) 

✨ Key Features
Legal Query Portal: A dedicated interface for users to submit their specific legal questions.
API-Powered Responses: Integrated external APIs to provide accurate and relevant legal information in real-time.
Simplified UI: Designed a clean and accessible layout to ensure ease of use for people from all backgrounds.
Responsive Design: Fully optimized to work on mobile, tablet, and desktop browsers.

📂 How to Run the Project
Clone or Download the repository to your system.Ensure you have an active internet connection (required for API fetching).
Open the index.html file in any modern web browser (Chrome, Firefox, or Edge).
Type a basic legal query in the input box to see the assistant in action.
